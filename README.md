# Wan2GP Pinokio Launcher

Leichter Launcher für Wan2GP in Pinokio.

## Schnellstart (3 Schritte)

1. In Pinokio öffnen
2. **Install** klicken
3. **Start** klicken

Danach öffnet sich die lokale Web-UI automatisch.

## Wichtige Dateien

- `install.js` – lädt Wan2GP und installiert Abhängigkeiten
- `start.js` – startet die App
- `update.js` – aktualisiert Launcher + App
- `reset.js` – setzt auf Installationszustand zurück
