# Security Policy

## Supported Versions

This repository tracks launcher scripts and metadata for Pinokio. Security fixes are made on the default branch.

## Reporting a Vulnerability

If you discover a security issue, please do **not** open a public GitHub issue.

Instead:
1. Contact the maintainer via direct message on X: https://x.com/cocktailpeanut
2. Or open a private security advisory on GitHub (if enabled for this repository).

Please include:
- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Suggested remediation (if known)

We will acknowledge reports as soon as possible and coordinate a fix/release plan.
